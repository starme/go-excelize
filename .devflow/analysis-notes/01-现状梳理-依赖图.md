# M1 素材：导入链路单向依赖关系图

## 契约层（excel.go）
所有接口均为空接口或约定式接口定义，无实现逻辑：
- `Excel interface{}` / `Rows interface{}` / `Sheet interface{}`（空接口，excel.go:9-13）
- 约定接口：`WithMultipleSheets`(Sheets) / `WithCollection`(Collection(ctx)) /
  `FromCollection`(Rows) / `WithSheetName`(SheetName) / `WithSkip`(Skip) /
  `WithHeading`(Headers) / `WithRows`(SheetRows) / `WithStyles`(Style) /
  `WithColumnWidths`(ColumnWidths) / `WithDataValidation`(DataValidation)

## 导入链路单向依赖
```
Importer (importer.go)
  └─> reader (reader.go)                 // newReaderOfPath/newReader
       └─> excelize.File                  // 底层库
  └─> scanner (scanner.go)
       ├─> reader.GetHeader / GetRows
       ├─> FieldMapper (scanner.go)
       │    └─> TypeConverter
       │    └─> parse/parseTag (column.go)  // column.go 是纯函数，被 FieldMapper.fillStruct 调用
       └─> RelationResolver (scanner.go)
            ├─> reader（子表加载）
            └─> FieldMapper
```

## 依赖方向判定
| 依赖 | 方向 | 结论 |
|------|------|------|
| importer → scanner | importer.imp 调 newScanner、s.scan | 单向，正确 |
| importer → reader | importer 持有 *reader | 单向，正确 |
| scanner → reader | scanner 持有 *reader | 单向，正确 |
| scanner → FieldMapper | newScanner 内 NewFieldMapper | 单向，正确 |
| FieldMapper → column.go | fillStruct 调 parse(target) | 单向，正确 |
| scanner → RelationResolver | newScanner 内 NewRelationResolver | 单向，正确 |
| RelationResolver → reader | rr.reader，getChildData 内 newScanner(rr.reader) | 单向，正确 |
| RelationResolver → FieldMapper | rr.fieldMapper | 单向，正确 |

**结论：单向依赖未被破坏。** 无反向依赖、无循环依赖。

但注意一点：`scanner` 同时持有 `fieldMapper` 与 `relationResolver`，而 `FieldMapper` 通过回调 `onRelation` 把关系字段的处理**反向委托**给 scanner（`fillStruct` 的 `onRelation` 参数 → `scanner.handleRelation` → `relationResolver.ResolveRelation`）。这是**回调注入**而非依赖反转，仍属单向（FieldMapper 不直接 import RelationResolver，通过函数签名连接）。可判定为合理，但 `FieldMapper.fillStruct` 的 `onRelation func(field, reflect.Value, reflect.Value) error` 签名过于具体（耦合了 `field` 私有类型），降低了 FieldMapper 的复用性。

## 导出链路（独立于导入）
```
Exporter (exporter.go)
  └─> excelize.File（直接操作，无 reader/scanner/column 参与）
  └─> Style.FormatStyle() / DataValidate.FormatDataValidate()（薄封装转换）
```
导出链路**完全不依赖 scanner/reader/column**，也**不解析 xlsx: 标签**。这是"单侧标签"的根源。
